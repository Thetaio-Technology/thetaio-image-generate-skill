# 参考图使用规则

用于用户提供图片,或要求“参考这张图的风格/构图/主体/配色”时。

## 先判断参考图角色

| 角色 | 含义 | 执行方式 |
| --- | --- | --- |
| 风格参考 | 只学习画风、色彩、质感、氛围 | 图生图或在提示词中描述风格特征 |
| 构图参考 | 保留布局、镜头、主体位置 | 图生图,提示词明确“保留构图” |
| 主体参考 | 保留某个物品、人物、角色、产品 | 图生图,提示词明确不可变元素 |
| 编辑目标 | 用户要直接改这张图 | 图生图,提示词写清楚保留项和修改项 |
| 辅助素材 | 多图合成或局部参考 | 多次 `--image`,并逐一说明角色 |

## 图生图提示词结构

```text
参考已上传图片。
保留: <必须保留的主体/构图/色彩/姿态/材质>。
改变: <要替换或增强的部分>。
风格: <目标风格>。
限制: <不能出现的元素、不能改变的元素>。
输出: <尺寸、用途、是否需要文字>。
```

## 保留主体时

- 明确写“保持主体身份、轮廓、比例和关键细节不变”。
- 对人物类图片,不要承诺完全一致的人脸; 只能要求尽量保留外观特征。
- 对产品图,写清楚品牌标志、包装文字、形状是否必须保持。没有授权时不要复制真实品牌标志。

## 只参考风格时

不要写“完全复刻”。应写:

```text
参考图只作为风格参考,学习其色彩、线条、材质和氛围,不要复制原图中的具体人物、品牌、构图或可识别元素。
```

## 批量图中使用参考图

- 如果首图是风格锚点,后续任务的 `ref` 指向首图输出。
- 如果用户提供的参考图是固定风格锚点,每个任务都可以使用同一个 `ref`。
- 如果每张图有不同参考图,在 `tasks.json` 中分别设置对应 `ref`。

## 风险提示

- 参考图中有受保护 IP、明星、真实品牌、教材封面时,默认只抽取抽象风格,不要复刻可识别元素。
- 参考图缺失或路径不存在时,直接停止,不要自动改成文生图。
