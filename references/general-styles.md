# 通用风格库

用于用户没有明确指定小红书风格,或需要封面、海报、知识卡、概念图、教程图、产品图时。

## 选择维度

每次先确定 5 个维度:

| 维度 | 可选值 | 说明 |
| --- | --- | --- |
| 用途类型 | 封面、概念图、字体海报、隐喻图、场景图、极简图、知识卡 | 决定信息密度和画面重心 |
| 色彩 | 暖色、优雅、冷色、暗色、自然、鲜艳、柔和、单色、复古、双色、马卡龙 | 决定情绪和受众 |
| 渲染 | 扁平矢量、手绘、绘本/水彩、数字插画、像素、粉笔、丝网印刷 | 决定质感 |
| 文字 | 无文字、仅标题、标题+副标题、信息丰富 | 决定图片内文字多少 |
| 情绪 | 克制、均衡、强冲击 | 决定对比度和视觉张力 |

## 自动选择规则

### 用途类型

| 内容信号 | 推荐类型 |
| --- | --- |
| 产品、发布、活动、上新、公告 | 封面 / 主视觉 |
| 架构、系统、模型、API、技术概念 | 概念图 |
| 金句、观点、标题、表达态度 | 字体海报 |
| 成长、哲学、抽象含义、反思 | 隐喻图 |
| 旅行、生活方式、故事、体验 | 场景图 |
| 专注、纯粹、极简、核心观点 | 极简图 |
| 教程、知识点、步骤、总结 | 知识卡 |

### 色彩

| 内容信号 | 推荐色彩 |
| --- | --- |
| 生活、情绪、人物、故事 | 暖色 |
| 商业、专业、高级感、思想领导力 | 优雅 |
| 技术、系统、数据、代码 | 冷色 |
| 电影感、娱乐、夜景、高端氛围 | 暗色 |
| 自然、健康、旅行、有机感 | 自然 |
| 促销、活动、游戏、强刺激 | 鲜艳 |
| 儿童、幻想、轻柔、亲和 | 柔和 / 马卡龙 |
| 极简、禅意、纯粹、专注 | 单色 |
| 怀旧、经典、历史、复古 | 复古 |
| 海报、专辑、电影、戏剧冲突 | 双色 |

### 渲染

| 内容信号 | 推荐渲染 |
| --- | --- |
| 干净、现代、图标、信息图 | 扁平矢量 |
| 笔记、随性、亲和、手作感 | 手绘 |
| 柔和、梦幻、儿童、绘本 | 绘本/水彩 |
| 数据、SaaS、企业、产品质感 | 数字插画 |
| 游戏、复古、8-bit | 像素 |
| 教学、课堂、教程 | 粉笔 |
| 强海报感、电影、音乐、限量版 | 丝网印刷 |

## 常用组合

| 名称 | 组合 |
| --- | --- |
| 优雅封面 | 优雅色彩 + 手绘/细线 + 克制情绪 |
| 蓝图科技 | 冷色 + 数字插画 + 概念图 |
| 黑板讲解 | 暗色 + 粉笔 + 知识卡 |
| 扁平涂鸦 | 柔和色彩 + 扁平矢量 + 手作装饰 |
| 自然手绘 | 自然色彩 + 手绘 + 场景图 |
| 极简观点 | 单色 + 扁平矢量 + 字体海报 |
| 复古海报 | 复古色彩 + 丝网印刷 + 强冲击 |
| 教育手绘 | 马卡龙 + 手绘 + 知识卡 |
| 水彩绘本 | 自然/柔和色彩 + 绘本/水彩 + 场景图 |
| 高对比活动图 | 鲜艳/双色 + 丝网印刷 + 强冲击 |

## 知识卡布局

| 布局 | 适合内容 |
| --- | --- |
| 密集卡片 | 总结、知识点、清单 |
| 列表 | 步骤、注意事项、排行榜 |
| 流程 | 教程、方法论、操作步骤 |
| 四象限 | SWOT、对比、矩阵分析 |
| 对比 | A/B、前后变化、优缺点 |
| 心智图 | 概念关系、分类、联想 |
| 稀疏视觉 | 封面、金句、强钩子 |

## 使用原则

- 先选用途类型,再选色彩和渲染。
- 不要把所有风格维度都拉满。强冲击色彩配强装饰时,文字要更少。
- 知识卡优先保证可读性; 插画优先保证主体和氛围。
- 用户给了参考图时,参考图优先于自动选择规则。
