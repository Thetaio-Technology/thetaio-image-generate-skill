# 提示词模板

## 单张提示词文件

每张图一个 `prompts/NN.md`:

```yaml
---
seq: 1
type: "单张"
size: "2K"
ratio: "3:4"
mode: "文生图"
ref: null
output: "<输出目录>/raw/01.png"
---
```

`size` 只填分辨率档位 `1K`/`2K`/`4K`;画幅比例写在 `ratio` 并同步到提示词正文。

正文使用自然语言,建议结构:

```text
用途: <这张图要解决什么问题>
主体: <画面核心主体,数量,姿态,关键细节>
场景: <环境,空间,前景/中景/背景>
构图: <镜头,主体位置,留白,层级>
风格: <渲染方式,材质,线条,年代感,参考风格>
色彩: <主色板,对比度,饱和度>
光线: <自然光/棚拍/柔光/夜景/逆光>
文字: <需要出现的短文字; 没有就写“无文字”>
限制: <禁止元素、版权/IP、标志、畸形、乱码等>
输出: <文件用途、画幅、是否作为同组风格锚点>
```

## 风格计划文件

`style-plan.md` 建议这样写:

```text
任务类型: <单张/参考图/批量/仅规划>
用途: <封面/海报/知识卡/产品图/插画/...>
输出目录: <路径>
尺寸: <1K/2K/4K>
画幅: <如 3:4>
参考资料: <读取了哪些 reference>
参考图: <无/路径/角色>
主风格: <风格名称>
色彩: <主色板>
构图: <主体位置、留白、镜头>
文字: <需要出现的短文字>
统一性: <批量图共享哪些规则>
禁止项: <版权/IP/品牌/文字密度/其他限制>
执行计划: <运行哪个脚本或仅输出提示词>
```

## 文生图提示词

适合无参考图的新图:

```text
生成一张 <用途> 图片。画面主体是 <主体>, 位于 <构图位置>。
背景为 <场景>, 使用 <风格> 风格, 色彩以 <主色板> 为主。
光线 <光线描述>, 画面层次清晰, 主体边缘干净。
画幅: <如 3:4 竖版>, 分辨率档位 <1K/2K/4K>。
文字要求: <无文字/短标题>。
禁止: 受保护 IP、真实品牌标志、真人明星、二维码、文字乱码、手指畸形、低清晰度、过度塑料质感。
```

## 小红书提示词

适合封面、知识卡、教程卡、种草图:

```text
图片规格: 小红书竖版 3:4,分辨率档位 2K,手机端优先阅读。
用途角色: <封面/铺垫页/核心页/总结页/结尾页>。
核心目标: <让用户 1 秒看懂什么,或保存什么>。
主体与场景: <核心主体、位置、环境、前景/中景/背景>。
版式: <稀疏/平衡/密集>,使用 <单主体/编号清单/双栏对比/流程步骤/思维导图/四象限/九宫格>。
文字: 主标题「<8-18 字短标题>」,关键词「<1-5 个短词>」,不要长段说明。
字体层级: 主标题最大,分区标题次之,关键词清晰可读;整体为 <手写/粉笔/干净黑体/展示字体>。
风格: <小红书风格预设或风格 A-H>,包含 <色彩、材质、渲染、装饰>。
安全区: 关键文字避开右上角和底部 10%-14%,主体和标题距离边缘 6%-8%。
限制: 不要二维码、真实品牌标志、受保护 IP、明星肖像、精确复刻教材封面、乱码、长段小字、廉价 AI 光效。
```

如果是强视觉海报或复古封面,可追加:

```text
丝网海报约束: 扁平色块,2-5 个主色,无渐变,半调网点,轻微套印错位,粗体标题,大面积负空间。
```

## 图生图提示词

适合有参考图:

```text
参考已上传图片,保留 <需要保留的主体/构图/色彩/姿态>, 改成 <目标风格或目标场景>。
不要改变 <不可变元素>。
增强 <需要增强的视觉点>, 保持画面自然、清晰、可发布。
禁止: <与任务相关的负向约束>。
```

## 批量任务文件

`tasks.json` 是数组。每项必须有 `output` 和 `prompt` 或 `prompt_file`:

```json
[
  {
    "prompt_file": "prompts/01.md",
    "output": "raw/01.png",
    "size": "2K"
  },
  {
    "prompt_file": "prompts/02.md",
    "output": "raw/02.png",
    "ref": "raw/01.png",
    "size": "2K"
  }
]
```

路径可写绝对路径,也可写相对 `tasks.json` 所在目录的路径。

如果是多张同风格图片,推荐第 1 张作为视觉锚:

```json
[
  {
    "prompt_file": "prompts/01.md",
    "output": "raw/01.png",
    "size": "2K"
  },
  {
    "prompt_file": "prompts/02.md",
    "output": "raw/02.png",
    "ref": "raw/01.png",
    "size": "2K"
  }
]
```

## 文字限制

图片内文字只适合短标题、关键词、数字、标签。超过 3 行的说明不要塞进图片提示词,放到外部文案或说明文件。

小红书图的中文尤其要短。模型生成中文不稳定时,下一版要减少图片内文字,保留标题和 1-3 个关键词即可。
